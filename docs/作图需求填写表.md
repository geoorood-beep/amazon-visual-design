# 作图需求填写表

填右栏，并附上产品照片；不知道的写“未知”。

| 项目 | 你填写 |
|---|---|
| 产品名称／型号／颜色 |  |
| 产品照片 | 请附图。素色底：正面、背面、侧面、正俯拍（旁边放尺子）、手放在旁边，每个配件单独一张。出场景图前会先用这些照片做造型基准给你逐张确认 |
| 产品尺寸 | 长 × 宽 × 高，注明单位 |
| 材质及对应部位 | 例如：顶部饮水盘是不锈钢 |
| 主要卖点及参数 | 按重要程度填写；参数注明来源，不确定的写未知 |
| 使用方式／功能触发条件 | 例如：电池供电，宠物靠近后出水 |
| 随产品销售的配件 |  |
| 要做哪些图／数量 | 主图__个方案；副图__张；A+__个模块；或只做测试图__张 |
| 必须保留／不能出现 |  |
| 参考图片或链接 | 可不填；注明“参考风格”或“保留原图内容” |
| 需要更改的默认设置 | 不改可不填：站点、语言、风格、尺寸等 |

默认：Amazon US、英文文案、现有AGENTS风格／字体／排版标准。主图每方案交付方图和竖图；A+每模块交付电脑和手机两版，均按现有默认尺寸制作。
