# Apple 品牌拆解

2026-11-18 整理。来源是 apple.com 的首页和产品页、Apple 新闻稿，以及广告行业媒体对几支广告的报道。每条观察后面附链接。这里只拆方法，不学品牌：我方画面和文案里不出现 Apple 的名字、标志、口号原句和产品。可直接借用的方法已经写进 `references/techniques.csv`，编号见每节末尾。

## 1. 它是谁，怎么定位自己

- 首页每个产品只配一句很短的话，常常只有两三个词，产品名就是主角，几乎不报参数。[apple.com](https://www.apple.com/)
- 同一条产品线里每一款都有一句定位，读下来就是一张清楚的选购表：最大的、最强的、最轻的、最值的。[iPhone 产品线](https://www.apple.com/iphone/)
- 广告长期走「真人、真事、真用户拍的照片」：Shot on iPhone 用用户和摄影师的手机照片做户外广告。[Apple 新闻稿](https://www.apple.com/newsroom/2017/01/behind-apples-new-campaign-one-night-on-iphone-7/)

## 2. 故事：讲人，不讲机器

- **一段时间里的几个真实瞬间。** 「一个晚上」从黄昏到天亮的一组照片，合起来讲一整夜。[Apple 新闻稿](https://www.apple.com/newsroom/2017/01/behind-apples-new-campaign-one-night-on-iphone-7/) → T01
- **人和宠物的感情。** 新年短片《Glad I Met You》讲一个女孩和一只走失小狗互相找到家，最重要的镜头是小狗跑向她，用慢动作拉长。[Muse by Clios](https://musebyclios.com/advertising/apples-chinese-new-year-film-is-stop-motion-love-between-humans-and-their-animals/) → T33、T25
- **用户自己的信。** 「Dear Apple」用真实用户写来的信讲手表帮了他们什么，只用用户自己的话。[MacRumors](https://www.macrumors.com/2025/09/13/dear-apple/)。我方没有真实用户评价，**不学**，更不能编。

## 3. 卖点：一次只讲一个，比较只和自己比

- **一张卡一个好处。** 耳机页先用一排卡片「Get the highlights」，每张只讲一个好处、一句话。[AirPods Pro](https://www.apple.com/airpods-pro/) → T45
- **部件名打头的一句话。** 「Take a closer look」里每个部件先写名字，再用一句话讲它带来什么。[AirPods Pro](https://www.apple.com/airpods-pro/) → T45
- **只和自己的上一代比，数字带脚注。** 「最多是上一代的 2 倍」，后面一个脚注编号。[AirPods Pro](https://www.apple.com/airpods-pro/) → T44
- **小身材配一个具体尺寸，大能力配一个具体画面。** 小音箱写「只有 3.3 英寸高，却能填满整个房间」。[HomePod mini](https://www.apple.com/homepod-mini/) → T46
- **材料和微距。** 微距挑战把很小的细节拍成整幅主角。[Apple 新闻稿](https://www.apple.com/newsroom/2022/04/apple-unveils-the-best-photos-from-the-shot-on-iphone-macro-challenge/) → T03

## 4. 场景：干净、留白、像用户自己拍的

- **大面积留白。** 产品页每一屏只有一个主体和一句话，背景干净。[AirPods Pro](https://www.apple.com/airpods-pro/) → T02、T32
- **用户视角实拍。** Shot on iPhone 的照片都是手机现场拍的，不布光。[Apple 新闻稿](https://www.apple.com/newsroom/2017/01/behind-apples-new-campaign-one-night-on-iphone-7/) → T06
- **宠物肖像。** 宠物照用高调黑白、全白背景，表情是唯一的焦点。[9to5Mac](https://9to5mac.com/2021/07/26/today-at-apple-pet-portraits-shot-on-iphone/) → T30

## 5. 标题：短、双关、有节奏

- **一语双关。** 降噪耳机写「你从没听过的最好的东西」，安静和好听在一句里；小音箱写「Fits right in」，既是放得下也是融得进。[AirPods Pro](https://www.apple.com/airpods-pro/)、[HomePod mini](https://www.apple.com/homepod-mini/) → T43
- **押韵两拍。** 「Feature stacked. Value packed.」[iPhone 产品线](https://www.apple.com/iphone/) → T47
- **三个形容词。** 「Powerful, durable, and delightful.」[iPhone 产品线](https://www.apple.com/iphone/) → T48
- **两拍短句。** 「Amazing performance. Durable design.」[iPhone 产品线](https://www.apple.com/iphone/) → T04
- **一个比喻代替参数。** 降噪广告把安静拍成噪音一个个飘走。[AppleInsider](https://appleinsider.com/articles/23/03/15/airpods-pro-noise-cancellation-featured-in-new-quiet-the-noise-ad) → T05

## 6. 互动、情绪、表情

- **情绪克制。** 广告主角大多平静、专注，很少大笑。[AppleInsider](https://appleinsider.com/articles/23/03/15/airpods-pro-noise-cancellation-featured-in-new-quiet-the-noise-ad) → T07
- **情绪高点用时间放大。** 慢动作，不用夸张表情。[Muse by Clios](https://musebyclios.com/advertising/apples-chinese-new-year-film-is-stop-motion-love-between-humans-and-their-animals/) → T33
- **手部演示干净利落。** 产品页的手势演示（按、滑）一次完成。[AirPods Pro](https://www.apple.com/airpods-pro/) → T26

## 7. 我方怎么用（汇总）

| 想做什么 | 用哪条手法 |
|---|---|
| 讲安静 | T43 一语双关、T05 一个比喻、T30 安静的专注 |
| 讲材质 | T03 材料本身当主角 |
| A+ 宫格和细节屏 | T45 一张卡一个好处 |
| 标题选项 | T43、T47、T48、T04 |
| 宠物和人的情绪 | T33 慢下来的情绪高点、T07 克制的满足、T25 被吸引回头 |
| 讲尺寸和容量 | T46（只在产品卡确认了尺寸时） |

## 8. 不学什么

- Apple 的名字、标志、口号原句、产品外形和界面。
- 「世界最好」「最准确」这类最高级说法。
- 和上一代比的数字：我方产品卡没有上一代时不用。
- 用户来信和评价：我方没有真实的，不编。
- 健康功能（心率、听力）这类功效说法。
