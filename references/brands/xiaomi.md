# 小米品牌拆解

2026-11-18 整理。来源是 mi.com 的关于我们、首页和产品页（宠物饮水机 2、宠物喂食器、15 Ultra），以及媒体对汽车发布会的报道。每条观察后面附链接。这里只拆方法，不学品牌：我方画面和文案里不出现小米的名字、标志、口号原句和产品。可直接借用的方法已经写进 `references/techniques.csv`，编号见每节末尾。

## 1. 它是谁，怎么定位自己

- 口号「Innovation for everyone」，使命是「做感动人心、价格厚道的好产品」，愿景是「和用户交朋友」。[小米 关于我们](https://www.mi.com/uk/about/)
- 关于页用几个大数字撑场：进入的市场数、月活用户、连接的设备数。我方品牌没有这类数据，**不学**。
- 产品之间讲「人、车、家」互相连起来。我方产品没有联网功能，**不学**。

## 2. 故事：从参数讲到「我家用得上」

- **参数后面接一个家庭场景。** 宠物饮水机写容量，后面接「一只猫能喝多少天、多猫家庭一周」，还写主人短暂外出时可以放心。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T10
- **发布会对标品类第一。** 汽车发布会把每项指标和行业标杆比。[Engadget](https://www.engadget.com/xiaomi-says-its-su7-ev-can-outperform-porsche-and-has-more-tech-than-tesla-095637762.html)。我方规范不点名竞品，只能和「普通水碗」「有线的方式」这种类别比 → T14

## 3. 卖点：参数大字报，条件写在小字里

- **整屏一个大数字。** 「100 天续航」「3L 大容量」各占一屏。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/)、[15 Ultra](https://www.mi.com/global/product/xiaomi-15-ultra/) → T13、T16
- **测试条件老老实实写在脚注里。** 续航、饮水天数后面都有小字：按什么条件测的、实际会不一样。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T39
- **拿生活小物比尺寸。** 喂食器说明粮粒大小，旁边放笔芯、7 号电池、5 号电池的直径作对照。[小米宠物喂食器](https://www.mi.com/global/product/xiaomi-smart-pet-food-feeder/) → T49
- **首屏一排功能标签。** 喂食器的首屏标题下面一行四个短标签，用竖线隔开。[小米宠物喂食器](https://www.mi.com/global/product/xiaomi-smart-pet-food-feeder/) → T51
- **无线对照有线。** 饮水机写「不用担心电线被咬」。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T14
- 注意：小米宠物页有抑菌、软化水质这类说法，后面附检测报告。我方规范禁止，**不学**。

## 4. 场景：一屏几个房间

- **几个房间并排。** 无线饮水机的「随处放」一屏，客厅、卧室、阳台三格并排。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T17
- **安静配卧室。** 「更安静」下面一行写「睡得安稳不被打扰」。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T34

## 5. 标题：短标题加一句好处，逗号两拍

- **短标题加一句好处。** 每节上面两三个词讲功能，下面一行讲生活好处。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T34
- **逗号两拍，常押头韵。** 首页一排：「Stay fit, stay sleek」「Wear your style, live with ease」「Easy sorting, better care」。[小米全球首页](https://www.mi.com/global/) → T50
- **数字打头。** 「3L large volume」「100-day long battery life」。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T16

## 6. 互动、情绪、表情

- **情绪是「省心」。** 宠物页反复讲主人不用操心：出门不用担心、晚上睡得安稳。[小米宠物饮水机 2](https://www.mi.com/ph/product/xiaomi-smart-pet-fountain2/) → T07、T38
- **语气像朋友，说实话。** 好处讲得直白，限制写在脚注里，不夸张。[小米 关于我们](https://www.mi.com/uk/about/) → T39
- 小米的宠物页以产品图为主，人和宠物的表情不多。表情看案例库和 Apple 的宠物肖像（T30）。

## 8. 不学什么

- 小米的名字、标志、口号原句、产品外形、App 界面。
- 联网、App 远程控制、生态联动：我方产品没有。
- 抑菌、软化水质、检测报告这类功效和认证说法。
- 点名竞品比较。
- 品牌大数字（用户数、市场数）。
- 产品卡没有的数字，比如续航天数、喝几天，「画面可写」没写就不用。
