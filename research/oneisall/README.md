# oneisall 研究素材索引

这些是 2026-11-15 从 Amazon US 页面截下来的竞品截图，只供内部设计研究。它们不是本品素材，不能当作 POKPET 的规格、检测或授权资产，也不能把画面里的商标、原句、徽章和健康承诺写进成品。

视觉尺寸的逐项测量见 [VISUAL_CASE_STUDY.md](VISUAL_CASE_STUDY.md)。页面模块的文字拆解见 [aplus_study.md](aplus_study.md)。可执行的生产规则在 `docs/LISTING_GALLERY_STANDARD_ONEISALL.md` 与 `docs/APLUS_STANDARD_ONEISALL.md`。

## 采集限制

- 直接请求商品页得到验证码，没有保存原始 A+ 上传文件。现有模块是 1464 宽的屏幕裁切，画质略软。
- B0BN2Z5CDC、B0C5X2G933、B0C5X4N132 的 A+ 首图顶部被懒加载截掉，文件名带 `TOPCUT`。
- 轮播只保留当时停住的那一页。本包没有单独的 `_full_strip.jpg`。整页联系图是 `sheets/<ASIN>_aplus.jpg`，高清半页是 `sheets/<ASIN>_aplus_hd_1.jpg` 与 `_2.jpg`。

## 跨产品对照

四页 A+ 共用一条骨架：Hero 与少量卖点、一个带参照的大数字、场景或功能 tab、2–3 个深潜、深色技术或信任模块、耗材或 App、自家对比表、品牌故事。高度大多是 1464×600。Premium 的 B0FN7FQ7RJ Hero 实测 1464×1175。带顶栏的轮播约 66 px 黑条加剩余图片。浅色场景和深色模块交替。轮播只拍到第一页，所以第一页必须自己讲完。

喂水器页把宠物放在产品旁边喝水或睡觉，数字是容量、分贝和续航。喂食器页更多用俯拍和地面标尺讲碗距，并用透明粮仓讲容量。人物主要出现在 Wi-Fi 款的手机场景和品牌故事里，不出现在喂水器副图的主体里。

采用的是顺序、明暗节奏、一个大数字加参照、圆角卡、放大镜、第一张轮播独立成立，以及自家对比表的行列。不采用的是健康句（healthier、kidneys、hygienic、safe for pets、purifying、black chin）、TOP 1、专利章、销量、奖项、媒体标志、质保数字、BPA 章，以及 SilentFlow™ 和其他商标。青柠到青色的渐变是无线款自己的强调色，不替换本项目的 `#F47A21`。参考页使用的几何无衬线也不替换已锁定的 Avenir Next。
