# oneisall A+ 模块与标准条款对照

日期：2026-11-15。30 个模块来自 `aplus_modules/` 的实有文件。文字依据 `aplus_study.md`，光线和尺寸依据 `VISUAL_CASE_STUDY.md` 与文件像素。本文件只建立对照，不改 `docs/APLUS_STANDARD_ONEISALL.md` 的含义。

字号档是相对 1464 宽的目测类别，不是字体文件测量：

| 档 | 含义 |
|---|---|
| H-hero | 首屏标题，约 60–72 px 级 |
| H-module | 模块标题，约 52–64 px 级 |
| N-hero | 主数字，约 110–160 px 级 |
| S-small | 参考页副句，目测低于标准要求的 36 px，只作反例 |
| chip | 图标标签或胶囊 |
| none | 几乎没有自绘标题 |

条款号指向该标准的现有章节。标「反例」的模块展示了标准禁止的内容，不是可复制的正例。
