# 验收

每张图出完后按本页检查一次。只有三项能判不合格，其余只记录、不拦截。

## 三项一票否决

| 编号 | 检查 | 怎么判 |
|---|---|---|
| V1 | 产品对 | 对照产品卡「外形识别点」逐条看。任何一条不符、多出部件或少了部件，不合格 |
| V2 | 卖点看得懂 | 遮住标题和数字，只看画面，能说出这张图的卖点。说不出，不合格 |
| V3 | 没有禁区内容 | 对照 `CORE.md` 第 8 节和产品卡「禁用词」。出现任何一项，不合格 |

## 记录项

下面几项只写「是 / 否」和一句说明。写「否」不重做，由人决定要不要改。

| 编号 | 记录 |
|---|---|
| R1 | 光的方向与图位卡一致，投影清晰 |
| R2 | 机位与图位卡一致 |
| R3 | 宠物的动作和神态与图位卡一致 |
| R4 | 文字是后期排版加上的，字体、层级、位置符合 `CORE.md` 第 5 节 |
| R5 | 实际像素（宽×高） |

## 重做规则

- 只有 V1、V2、V3 不合格才重做，最多重做 2 次。
- 每次重做前写一句：这次改什么。不允许不改提示词就重新生成。
- 重做 2 次仍不合格：停下，把最好的一张作为候选交出来，写明哪一项没过。不继续重试。
- 记录项写「否」不触发重做。
- 不因为像素、画幅的取整误差或任何测量数值重做。

## 回报格式

每张图只回报下面这些内容，不加别的：

```
图位：S5
附带的参考图：
  products/round10l/ref/front_high.png
  references/anchors/v06_S6_clean_sink.png
  docs/uta_style_v3/assets/key/EXP_011.jpg
生成次数：1（重做 0 次）
V1 产品对：通过
V2 卖点看得懂：通过
V3 没有禁区内容：通过
R1 光：是
R2 机位：是
R3 宠物：是
R4 文字：是
R5 像素：1122×1402
输出文件：outputs/round10l/S5_clean_v01.png
```

「附带的参考图」必须是这次生图调用里真正作为图片输入传进去的文件。没有传进去的不要列。如果生图工具这次没有接收图片输入，写「未附带」并说明原因。
