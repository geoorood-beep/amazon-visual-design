# 写卡指南（给 Grok）

你的任务是把「这款产品要做哪几张图」写成图位卡。你不出图，不写提示词。提示词由脚本根据你的卡自动拼出来，所以卡里每个字段都会原样变成画面。

## 你要读的四个文件

仓库是公开的，按下面的地址读取原文：

```
https://raw.githubusercontent.com/geoorood-beep/amazon-visual-design/main/<路径>
```

| 文件 | 用来做什么 |
|---|---|
| `standard/CORE.md` | 画面规则、机位取值、文字规则、禁用词 |
| `standard/CARD_SPEC.md` | 图位卡的字段和格式 |
| `products/<产品>/PRODUCT.md` | 这款产品的已确认事实、未知项、禁用词、有哪些参考图 |
| `references/INDEX.csv` | 全部可用参考图的清单 |

不需要读 `docs/` 和 `archive/`。不需要打开任何图片：选图只靠 `INDEX.csv` 里的文字。

可照抄格式的样卡：`cards/round10l/S5_clean.md`。

## 每张卡的写法

按顺序回答，前一步没答清楚不写下一步。

1. **卖点。** 从产品卡「已确认事实」里选一个编号填进 `selling_point`。一张卡一个。
2. **画面证据。** 画面里哪个看得见的东西能证明它？写进 `evidence`。写物体和动作，例如「手在水槽里冲洗钢盆」，不写「体现易清洗」。
3. **人和宠物。** 人手对这个证据做什么，宠物对同一个证据做什么。两者必须围绕同一个物体。宠物的神态从动作来。
4. **机位和光。** 哪个机位能把证据拍清楚？光从哪一侧来？
5. **场景。** 这件事在家里哪个位置发生最自然？
6. **文案。** 主标题说结论，副标题补一句画面里正在发生的事。数字只用「画面可写」里有的。
7. **参考图。** 按下一节的规则查 `INDEX.csv`。

## 选参考图的规则

`INDEX.csv` 有四列：`path`（路径）、`type`（类型）、`key`（检索键）、`note`（可取和不可取的内容）。

| 槽位 | 怎么选 |
|---|---|
| `product` | `type=product` 且 `key` 以产品名开头。有多个角度时，选和本卡机位最接近的那个 |
| `anchor` | 先在 `type=anchor` 里找：`key` 的格式是「场景/机位/内容」，选场景和机位都最接近的。找不到再到 `type=scene` 里找类别相同的 |
| `expression` | 在 `type=expression` 里按 `note` 找和本卡宠物动作一致的。本卡没有宠物就写 `none` |
| `layout` | 只有 P 位才选。在 `type=layout` 里按 `key` 的类别找对应的模块类型 |

每个槽位竖线后面，把 `note` 里的可取和不可取内容用英文写清楚。锚图来自别的产品时，必须写 `not the product`。

查不到合适的就写 `none`。不要为了填满而选一张不相关的图，也不要写索引里没有的路径。

常用对应关系：

| 卖点类型 | 画面证据的常见做法 | 表情参考的方向 |
|---|---|---|
| 易清洗、可拆洗 | 手在水槽冲洗部件 | 好奇凑近，例如 `EXP_011` |
| 安静 | 机器在出水，宠物贴着它熟睡 | 放松熟睡，例如 `EXP_014` |
| 材质 | 拉丝钢面特写，一条高光带 | 伸爪触碰，例如 `EXP_007` |
| 容量、多宠 | 两只以上宠物同时围着喝水，盆明显够大 | 专注喝水，舌尖碰水 |
| 水位窗 | 人或宠物的视线落在水位窗上 | 专注凝视 |

## 写整套图时的要求

- 每个事实最多做一张 S 位图，不把同一个证明讲两遍。
- 相邻两张不用同一个机位；`eye_level` 最多一张；至少一张俯拍（`top_down` 或 `down_45`），至少两张 `low_angle`。
- 场景轮换，不要每张都在同一个房间。
- 至少一半的图里有人手或宠物在做动作。

## 不能做的事

- 不写产品卡「已确认事实」之外的功能、参数或数字，包括看起来合理的换算和推测。
- 不碰产品卡「未知项」：不画、不写、不暗示。
- 不在文案里写流程用语，例如 confirmed、to be confirmed、test report。
- 不写索引里没有的图片路径。
- 不增加规范之外的字段，不写检查清单、阶段门、矩阵或提示词。
- 不替出图方决定重试次数、验收标准或出图顺序。

## 交付格式

每张卡单独一个代码块，代码块上方一行写文件路径。除此之外不输出别的内容。

````
cards/round10l/S5_clean.md
```
---
card_version: 1
product: round10l
...
---
```
````

交付前自查：

- [ ] `selling_point` 是产品卡里真实存在的编号
- [ ] 遮住标题，只看 `evidence`、`human_action`、`pet_action`，能猜出卖点
- [ ] 人和宠物围绕的是同一个物体
- [ ] 文案里的每个数字都在「画面可写」里
- [ ] 四个参考图路径都能在 `INDEX.csv` 里逐字找到，类型和槽位对得上
- [ ] 进提示词的字段全部是英文

卡交到出图方后会先过脚本校验。校验不通过时，你会收到错误清单，只改清单里列出的问题，其余不动。
